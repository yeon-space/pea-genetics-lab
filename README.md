# 완두 유전 실습실 (Pea Genetics Lab)

멘델의 유전 법칙을 대화형 드래그 앤 드롭 카드 및 시뮬레이터로 학습할 수 있는 웹 애플리케이션입니다.

## 주요 기능
- **멘델의 완두 선택 이유**: 카드 드래그 앤 드롭 학습
- **수분 개념**: 자가수분 및 타가수분 비교
- **완두 유전 시뮬레이터**:
  - 1단계: 순종 어버이 생식세포 교배 (자손 1대)
  - 2단계: 자손 1대 자가수분
  - 3단계: 퍼넷 사각형(Punnett Square) 표 채우기 및 표현형 비율 확인

## 실행 방법
`index.html` 파일을 웹 브라우저에서 열면 바로 실행됩니다.
